# Expense Tracker - SDC Project

## Requirements covered
- Admin Module
- User Module
- HTML, CSS and JavaScript only
- CSS Grid and Flexbox
- Signup and Login using Local Storage
- JavaScript module navigation
- Expense, income and budget management
- Multiple accounts
- Recurring expenses
- Reports and CSV export
- GitHub-ready folder structure

## Run
Open `index.html` in a browser. No server or database is required.
